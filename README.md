Тестовое задание на позицию Backend-разработчика. Проект представляет собой легковесное API-решение для управления позициями строительной сметы с автоматическим подсчетом стоимостей и возможностью применения наценки.

Функционал
- Добавление позиций: Принимает название, количество и цену за единицу (с валидацией данных).
- Хранение в БД: Используется база данных SQLite.
- Динамический расчет сумм: Сразу вычисляется стоимость каждой позиции (количество * цена) без сохранения вычисляемых лишних полей в БД.
- Удаление позиций: Удаление элементов сметы по их ID.
- Расчет общего итога (Бонусное задание): Возвращается сумма всех позиций (subtotal) и финальный чек с учетом коэффициента/наценки в процентах (grand_total).

Стек технологий
- Язык программирования: Python
- Фреймворк: FastAPI
- База данных: SQLite
- ORM: SQLAlchemy
- Валидация: Pydantic
